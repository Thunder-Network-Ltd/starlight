## 小幻影视

一款 Windows 桌面端的媒体聚合播放器，同时支持 Emby、Jellyfin、Plex 与本地文件服务。界面贴合
Fluent 设计，支持 4K 原画播放、多版本与多音轨切换、弹幕匹配，并可从 Hills、AfuseKt、Yamby
等客户端一键导入已有配置。

### 下载安装

前往[微软商店](https://apps.microsoft.com/detail/9nb0h051m4v4)下载，付费应用。

### 设置方法

在左侧「服务列表」点击 **+** 号选择 **Emby**，填写显示名称、服务器地址（从面板个人概览复制的线路地址）以及
Emby 用户名与密码，点击**测试连接**确认可用后**创建**即可。
