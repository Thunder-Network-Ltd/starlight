最后更新：2026 年 10 月 1 日

我们重视您的隐私。本政策说明 Lumen 在您使用控制台、媒体服务与网页播放器时收集哪些信息、如何使用与保护这些信息、保存多久，以及您享有的权利。

## 一、我们收集的信息

**账号信息**：注册时提供的邮箱、用户名和密码（只保存经不可逆处理的哈希值），您自行上传的头像，以及您是通过谁的邀请链接注册的。开启两步验证或添加通行密钥时，我们保存验证器密钥、恢复码的哈希值和通行密钥的公钥。

**登录信息**：

- 控制台：每次登录的 IP 地址和浏览器信息（User-Agent），以及该次登录最近一次使用的时间与 IP 地址；添加通行密钥时，根据浏览器信息生成的名称（如「Safari · iPhone」）。
- 播放客户端：客户端名称与版本、设备名称、设备编号、首次登录与最近活跃的时间，以及最近一次登录时的 IP 地址。

**观看信息**：

- 观看记录：看过的内容、播放进度、是否看完、播放次数、最近播放时间、收藏与评分，以及您在「继续观看」中隐藏的条目、客户端的显示偏好、媒体库的排序与您创建的自定义媒体库。
- 观看统计：按小时汇总的观看时长与起播次数，以及当时所用的客户端、设备和播放方式。

**流量信息**：按分钟汇总的各线路流量；按天汇总的访问 IP 地址，以及经各 IP 地址、各线路产生的流量、请求次数与首末访问时间；按分钟汇总的各内容的播放流量。

**订阅与交易记录**：订阅与续订记录、余额与余额变动明细、充值订单、兑换码的创建与使用记录、折扣码的使用记录、邀请返利与返利余额的变动记录。充值时，我们记录订单金额、支付方式，以及支付渠道返回的交易号与支付结果。支付在支付渠道的页面完成，**我们不会接触或存储您的银行卡号、支付账号、支付密码等支付凭据**。

**您提交的内容**：客服工单的内容与截图，求片及其补充说明，片源问题反馈及其中的留言。一起看的聊天消息只在房间内实时转发，不会保存。

**邮件与验证记录**：邮箱验证码（只保存哈希值）与提醒邮件的发送记录（用于避免重复发送）。

**IP 地址归属信息**：核查账号的播放来源时，系统会查询相关 IP 地址的大致地理位置与网络运营商，并保存查询结果。

**排障记录**：媒体服务会记录播放客户端发出的请求与服务器的响应，用于排查客户端兼容问题。记录中不含 IP 地址与密码，登录凭据与设备编号只以不可还原的摘要形式保存。

## 二、信息的使用

我们只将上述信息用于：

1. 提供并维护服务：开通播放权限、同步观看进度、管理订阅、统计流量、处理充值、兑换与返利；
2. 发送邮件：验证码、安全提醒、客服工单回复与自动续订的扣款预告、扣款回执；订阅到期、余额不足与流量提醒，以及求片与反馈的处理结果（这两类可在账号设置中关闭）；
3. 安全与风控：识别账号共享、盗号、恶意刷流等异常行为；
4. 改进服务：基于整体的统计数据优化线路与片库，并生成「本服热门」等整体排行（排行中不显示任何个人信息）。

我们**不会**出售您的个人信息，也不会将其提供给与提供服务无关的第三方。

## 三、Cookie 与本地存储

控制台使用 Cookie 保持登录状态，并在浏览器本地存储中记住界面偏好（如主题、片库排序、播放倍速与弹幕显示）。禁用 Cookie 会导致无法保持登录。

## 四、第三方服务

服务运行依赖以下第三方，它们仅在完成对应功能所需的范围内接触数据：

- **支付渠道**（支付宝 / 微信及聚合支付服务商）：处理充值。下单时，我们向其发送订单号、金额、商品名称、您的 IP 地址、设备类型（电脑或手机），以及用于对账的内部账号编号（不含邮箱和用户名）；您在支付页面填写的信息由支付渠道直接处理。
- **UserCheck**：检测一次性邮箱等无法正常使用的邮箱地址。在注册页或更换绑定邮箱时填写邮箱后（邮箱输入框失去焦点时），以及发送注册或更换邮箱的验证码时，我们会将**完整的邮箱地址**发送给 UserCheck 查询。
- **Cloudflare**：人机验证（Turnstile），用于注册、找回密码、更换绑定邮箱，以及被判定需要验证的登录，校验时会收到您的 IP 地址；部分线路经 Cloudflare 传输；数据库备份存放在 Cloudflare R2 对象存储中。
- **内容分发网络与线路服务商**：传输控制台页面与播放数据，传输过程中会处理您的 IP 地址。
- **IP 归属查询服务**：核查账号的播放来源时，查询相关 IP 地址的归属地；仅发送 IP 地址，不附带账号信息。
- **邮件发送服务**：发送验证码与通知邮件，会收到您的邮箱地址与邮件内容。
- **影视资料来源**（TMDB、豆瓣等）：获取片库的影片资料与图片。求片时，您输入的搜索词或所贴链接中的条目编号会发送给这些资料站查询，不附带账号信息；播放客户端请求的海报尚未缓存时，媒体服务向 TMDB 取图的请求中会带有您客户端的标识（User-Agent）；求片与反馈通知邮件中的海报由您的邮件客户端直接从 TMDB 加载。
- **Telegram**：通过官方 Telegram 客服联系我们时，您的 Telegram 账号信息（如 ID、名称、用户名）与消息内容经 Telegram 转发给客服人员；首次使用需完成人机验证（Cloudflare Turnstile）。官方交流群与 Discord 社群受对应平台的隐私政策约束。

## 五、信息的存储与保护

1. 账号密码经不可逆哈希处理存储，任何人（包括管理员）都无法查看您的原始密码。
2. 数据存储在受访问控制保护的服务器上，仅限运营必需的人员访问。管理员在处理工单、排查问题与风控时，可以查看您的账号、订阅、流量、设备与观看记录。
3. 尽管我们采取合理的安全措施，互联网传输无法保证绝对安全，请妥善保管您的账号并开启两步验证。

### 保存期限

| 信息 | 保存期限 |
| --- | --- |
| 账号信息、订阅与交易记录、客服工单、求片与反馈 | 账号存续期间（注销时的处理见第六节） |
| 按线路、按 IP 地址汇总的流量 | 账号存续期间 |
| 按内容汇总的播放流量 | 90 天，到期自动删除 |
| 观看统计 | 默认 400 天，到期自动删除 |
| 观看记录、播放客户端的登录记录 | 目前不自动删除，账号注销后仍会保留（见第六节） |
| 控制台登录记录 | 登录失效满 30 天后，在您下次登录时删除 |
| 邮箱验证码、提醒邮件的发送记录、IP 地址归属查询结果 | 目前不自动删除 |
| 排障记录 | 默认 30 天，其中较大的请求与响应内容目前不自动删除 |
| 数据库备份 | 控制台数据库每 6 小时备份一次，保留最近 7 天；媒体服务数据库每天备份一次，保留最近 14 天 |

## 六、您的权利

1. **查看与更正**：账号信息（用户名、邮箱、头像、密码、两步验证、通行密钥与邮件通知偏好）可在控制台的账号设置中自助管理。
2. **会话控制**：可在控制台「账号设置」中逐台移除播放设备、逐个退出网页登录，或随时在所有设备上退出登录。
3. **注销与删除**：控制台暂不提供自助注销，如需注销账号，请通过第八节的渠道联系我们，我们会在核实身份后人工处理。
   - 没有付款、余额与余额变动记录的账号可以删除。删除后，控制台中的账号信息、登录记录、两步验证与通行密钥、订阅、流量统计、客服工单（含截图）以及您在求片与反馈中的参与记录随之删除。您在片源问题反馈中发表的留言会保留在该反馈下，但不再显示发表人；后台操作记录中会保留一条删除记录（含当时的邮箱与用户名），用于核查管理操作。
   - 有已支付订单、余额或余额变动记录的账号不能删除，只能停用。停用后无法登录与播放，账号信息与交易记录会继续保留，用于对账和处理可能的争议。
   - 媒体服务中的账号在注销或停用时只会被停用：观看记录、播放客户端的登录记录（含最近一次登录的 IP 地址）、显示偏好与自定义媒体库会继续保留，观看统计按上表的期限自动删除。如需一并删除这些记录，请在申请时注明，由客服人工处理。
   - 已删除的数据在数据库备份中还会保留至多 14 天，随备份轮换清除。

## 七、政策更新

本政策更新后会修改页首的「最后更新」日期，重大变更会通过控制台系统通知或邮件告知。

- **官方 Telegram 客服**：[@Lumen_Customer_bot](https://t.me/Lumen_Customer_bot)，无法登录控制台时请使用此渠道；

为保护您的隐私，请勿在公开的交流群或 Discord 中发送账号、订单等个人信息。
