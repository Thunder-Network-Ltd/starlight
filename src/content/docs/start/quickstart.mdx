---
title: 快速开始
description: 注册、订阅、复制线路地址，然后在客户端中登录。
---

import { Steps } from '@astrojs/starlight/components';

<Steps>

1. ### 注册账号

   在 [lumen.ax](https://www.lumen.ax) 点击 **免费注册**。用户名也是客户端的登录名。收到好友的邀请链接时，请通过邀请链接注册。

2. ### 充值并订阅

   在 **[余额充值](https://www.lumen.ax/dashboard/wallet)** 用支付宝或微信充值，再到 **[服务订阅](https://www.lumen.ax/dashboard/subscription)** 选择套餐。各套餐片库相同，区别在于线路和流量，见[套餐、线路与流量](/start/plans/)。首次订阅默认开启自动续订，可随时关闭。

3. ### 复制线路地址

   在控制台首页点击 **播放线路**，复制任一地址，它就是客户端里的服务器地址。

4. ### 在客户端中登录

   添加一台 **Emby** 服务器，填写线路地址和 Lumen 用户名（或邮箱）、密码。各设备的步骤见 [iPhone · iPad · Apple TV](/clients/apple/)、[Android 与电视](/clients/android/)、[Windows 与 Mac](/clients/windows/)。

</Steps>

不想安装客户端，也可以在控制台的[在线观影](/watch/web/)中直接用浏览器观看。建议在[账号设置](/panel/account/)中开启两步验证，保护钱包余额。
