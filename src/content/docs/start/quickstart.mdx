从注册到开始观看只需四步，大约五分钟。

<Steps>

1. **注册账号**

   在 [lumen.ax](https://www.lumen.ax) 点击 **免费注册**，填写用户名、邮箱和密码。用户名也是您在客户端中的登录名。如果收到了好友的邀请链接，请通过邀请链接注册。

2. **充值并订阅**

   在[余额充值](https://www.lumen.ax/dashboard/wallet)中用支付宝或微信充值，再到[服务订阅](https://www.lumen.ax/dashboard/subscription)选择套餐。各套餐的片库相同，区别在于可用线路和流量额度，详见[套餐、线路与流量](/start/plans/)。首次订阅默认开启自动续订，可以随时关闭。

3. **复制线路地址**

   回到控制台首页，点击 **播放线路**，复制任意一条线路地址。这就是客户端中要填写的服务器地址。

4. **在客户端中登录**

   在客户端中添加一台 **Emby** 服务器，填写线路地址，以及您的 Lumen 用户名（或邮箱）和密码。各设备的具体步骤见下方。

</Steps>
