Lumen 是一项私人流媒体服务，提供持续更新的高画质片库。您可以使用熟悉的 Emby 客户端（Infuse、Yamby、Hills 等）观看，也可以直接在浏览器中观看。

与多数 Emby 服务不同，Lumen 的控制台与媒体网关均为自主研发。Lumen 兼容主流 Emby 客户端，同时在播放、片库、账号与线路等环节采用了不同的设计。

## Lumen 媒体网关

Lumen 媒体网关是 Lumen 自主研发的媒体服务端，兼容 Emby Server 协议。目前，Lumen 的账号认证、播放与片库管理均由媒体网关直接承担，不再运行 Emby Server。

### 为什么自行开发

Emby 拥有覆盖几乎所有平台的客户端生态，这也是 Lumen 选择兼容 Emby 协议的原因。但 Emby Server 的设计目标是家庭与小规模场景，在大型片库与多用户同时观看的场景下，存在一些固有的限制：

- 片库存放在网盘等远程存储时，新增内容依赖定期扫描，片库规模越大，入库越慢
- 缺少针对高码率片源的读取策略，4K 原盘等内容容易出现缓冲
- 片库扫描、元数据刮削等后台任务与用户播放争用资源，任务繁忙时会影响播放
- 中文片名的检索能力有限
- 账号需要单独管理，无法与订阅、线路等服务统一

Lumen 媒体网关针对这些场景重新设计，同时与主流 Emby 客户端保持兼容，您无需更换已经习惯的客户端。

### 主要特性

- **按码率自动预读**：播放时，网关会根据片源码率提前读取后续内容，码率越高，提前准备的数据越多。即使是 4K 原盘等高码率片源，也能减少缓冲与卡顿。
- **播放优先**：网关为播放请求保留专用的资源。片库扫描、元数据刮削等后台任务无法占用这部分资源，即使后台任务繁忙，正在进行的播放也不受影响。
- **多级缓存**：服务器设有影片数据缓存与图片缓存。近期播放过的内容与海报可直接从缓存读取，热门影片的起播与片库浏览因此更快。
- **新片快速入库**：网关实时感知片库存储的变化，新增的影片与剧集通常在一分钟内出现在片库中，海报与简介随后自动补全。
- **中文检索**：输入片名的任意片段即可检索，例如搜索「星际」即可找到「星际穿越」；检索时同时匹配中文名与原名。
- **统一账号**：客户端直接使用您的 Lumen 账号登录，无需单独的 Emby 账号。修改密码或移除设备后，相关设备会立即登出。

### 与 Emby Server 的对比

| 项目 | Emby Server | Lumen 媒体网关 |
| --- | --- | --- |
| 新片入库 | 依赖定期扫描，片库越大越慢 | 实时感知变化，通常一分钟内入库 |
| 高码率播放 | 缺少针对性的预读策略 | 按码率自动预读，减少缓冲 |
| 资源调度 | 后台任务与播放争用资源 | 播放优先，不受后台任务影响 |
| 中文检索 | 检索能力有限 | 支持片名任意片段检索，同时匹配原名 |
| 账号 | 需单独管理 Emby 账号 | 与控制台共用一个账号 |

## 服务理念

## 团队

Lumen 由一支技术人员与影视爱好者组成的团队开发和运营。团队成员在媒体库维护、网络优化与产品研发领域均有多年经验，合作已超过五年。我们以做产品的标准运营 Lumen：统一的界面语言、清晰的使用路径、稳定的运行表现，以及可预期的长期维护。
