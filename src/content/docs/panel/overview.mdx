登录[控制台](https://www.lumen.ax/dashboard)后，默认进入**个人概览**页面。该页面汇集了最常用的信息：订阅剩余天数、流量使用情况，以及客户端中应填写的地址。当前登录您账号的设备请在[账号设置](/panel/account/#播放设备与网页登录)中查看。

## 顶部信息卡片

| 卡片 | 显示内容 |
| --- | --- |
| **当前订阅** | 套餐名称与剩余天数；从未订阅时显示「未订阅」，订阅到期后显示「已到期」或「续订未成功」 |
| **流量信息** | 本期已用量 / 总量（如 `120 / 512 GB`）及剩余百分比，详见[线路与流量](/start/plans/#流量) |
| **余额** | 当前余额；如已开启自动续订，将注明「已开启自动续订」 |
| **本周观看 / 本月观看** | 观看分钟数与次数，随下方图表的 7 天 / 30 天切换同步变化 |

本期流量用完时，卡片上方会显示「本期流量已用完」提示并注明恢复时间；有更高档的套餐可以升级时提供 **升级套餐** 按钮，当前订阅即将到期且未开启自动续订时提供 **去续费** 按钮。详见[流量用完之后](/start/plans/#流量用完之后)。

## 播放线路

点击 **播放线路** 卡片，将列出您当前套餐可用的全部线路，即客户端中「服务器地址」一栏应填写的内容。

- 每条线路包含名称和一句说明。地址默认模糊显示，**将鼠标悬停在地址上（在手机上轻点）后才会显示**，右侧提供复制按钮
- 带有 **流量 ×0.5** 等标签的线路，表示使用该线路时流量按此倍率计入：绿色表示倍率低于 1 倍，可节省流量；橙色表示倍率高于 1 倍，流量消耗较大
- 仅在订阅生效期间才会列出线路，不同套餐可用的线路不同

客户端使用**本站账号（用户名或邮箱）和密码**登录，不设单独的 Emby 密码。完整的填写方法请参阅[连接信息](/clients/connect/)，线路的选择方法请参阅[套餐、线路与流量](/start/plans/)。

## 快捷入口

另有三张卡片可直接进入常用页面：**在线观影**（在网页上直接观看）、**余额充值**（购买订阅与创建兑换码）和**求片与反馈**（提交求片、反馈片源问题；有新进展时卡片上会提示）。

## 观看统计与热门排行

页面下半部分包含三张图表：

- **我的观看次数**：电影 / 剧集各自的观看次数，以及与上一周期的对比
- **我的观看时长**：可切换「最近 7 天 / 最近 30 天」，显示合计时长与日均时长
- **本周热门 / 本月热门**：全站观看人数最多的电影与电视剧，点击条目可查看详情或跳转至 TMDB

暂时没有统计数据时，图表显示「暂无观看数据」（热门排行显示「暂无排行数据」）；尚未开通订阅时，还会提供「去开通订阅」按钮。

## 系统通知

拥有生效中的订阅且有已发布的公告时，页面顶部会显示一条**系统通知**横幅，展示最新公告的摘要，点击即可查看全部通知。维护、线路调整等消息均会在此发布，遇到异常时请先查看此处。
