登录[控制台](https://www.lumen.ax/dashboard)后，默认进入**个人概览**页面。该页面汇集了最常用的信息：订阅剩余天数、流量使用情况、客户端中应填写的地址，以及当前登录您账号的设备。

## 顶部信息卡片

| 卡片 | 显示内容 |
| --- | --- |
| **当前订阅** | 套餐名称与剩余天数；未订阅时显示「未订阅」 |
| **流量信息** | 本期已用量 / 总量（如 `120 / 512 GB`）及剩余百分比，详见[线路与流量](/start/plans/) |
| **钱包余额** | 当前余额；如已开启自动续订，将注明「已开启自动续订」 |
| **本周观看 / 本月观看** | 观看分钟数与次数，随下方图表的 7 天 / 30 天切换同步变化 |

## 播放线路

点击 **播放线路** 卡片，将列出您当前套餐可用的全部线路，即客户端中「服务器地址」一栏应填写的内容。

- 每条线路包含名称和一句说明。地址默认模糊显示，**将鼠标悬停在地址上（在手机上轻点）后才会显示**，右侧提供复制按钮
- 带有 **流量 ×0.5** 等标签的线路，表示使用该线路时流量按此倍率计入：绿色表示倍率低于 1 倍，可节省流量；橙色表示倍率高于 1 倍，流量消耗较大
- 仅在订阅生效期间才会列出线路，不同套餐可用的线路不同

客户端使用**本站账号（用户名或邮箱）和密码**登录，不设单独的 Emby 密码。完整的填写方法请参阅[连接信息](/clients/connect/)，线路的选择方法请参阅[套餐、线路与流量](/start/plans/)。

## 我的设备

点击 **我的设备** 卡片，可查看当前使用您账号登录的播放客户端。每台设备会显示客户端名称和「最近活跃」时间。

- 如发现不认识的设备，请点击右侧的 **移除**，该设备需重新登录才能继续播放
- 如需一次性退出所有设备，请前往[账号设置](/panel/account/#退出所有设备)并点击「退出所有设备」
- 部分旧版客户端不上报设备编号，此类设备没有移除按钮，只能通过「退出所有设备」或修改密码使其登出

<Aside type="tip">
	如发现陌生设备，请先将其移除，再前往[账号设置](/panel/account/)修改密码。修改密码后，所有客户端都需要重新登录。
</Aside>

## 快捷入口

另有两张卡片可直接进入常用页面：**余额充值**（购买订阅与创建兑换码）和**片库反馈**（提交您希望观看的影视资源）。

## 观看统计与热门排行

页面下半部分包含三张图表：

- **我的观看次数**：电影 / 剧集各自的观看次数，以及与上一周期的对比
- **我的观看时长**：可切换「最近 7 天 / 最近 30 天」，显示合计时长与日均时长
- **本周热门 / 本月热门**：全站观看人数最多的电影与电视剧，点击条目可查看详情或跳转至 TMDB

尚未开通订阅时，图表显示「暂无观看数据」，并提供「去开通订阅」按钮。

## 系统通知

拥有生效中的订阅时，页面顶部会显示一条**系统通知**横幅，展示最新公告的摘要，点击即可查看全部通知。维护、线路调整等消息均会在此发布，遇到异常时请先查看此处。
