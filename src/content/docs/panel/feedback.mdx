求片与报错均在控制台的 **[片库反馈](https://www.lumen.ax/dashboard/feedback)** 页面提交。点击右上角的 **新增反馈**，选择类型后填写相关内容即可。

<Aside type="tip" title="求片前请先搜索">
	请先在[在线观影](/watch/web/)中搜索片名。如未找到结果，结果页会提供 **提交求片** 按钮，点击后将直接打开求片窗口并自动带入片名。
</Aside>

## 提交反馈

<Tabs>
<TabItem label="影片请求（求片）">

1. 在 [TMDB](https://www.themoviedb.org/) 或[豆瓣](https://movie.douban.com/)中找到该影片，打开其**详情页**，并复制地址栏中的链接
2. 将链接粘贴到「粘贴 TMDB 或豆瓣详情页链接」一栏，系统会自动识别片名
3. 「补充说明」为选填项，可注明所需的版本、从第几季开始等
4. 选择优先级（低 / 中 / 高），点击 **提交反馈**

请务必粘贴**详情页**链接，而非搜索结果页链接。由于同名影片较多，详情页链接可以准确定位到您需要的影片。TMDB 链接须为电影或剧集页面，不支持人物页或合集页。

</TabItem>
<TabItem label="错误反馈（报错）">

1. 填写**出错媒体的标题**
2. 描述问题，**剧集请具体到季和集**，例如「第 2 季第 5 集没有中文字幕」
3. 可附上该条目的链接，以便快速定位
4. 选择优先级，点击 **提交反馈**

适用的反馈类型：缺集、文件损坏（播放中途中断、花屏）、音画不同步、字幕缺失或错位、海报或简介错误等。

</TabItem>
</Tabs>

<Aside type="note" title="区分资源问题与播放问题">
	请使用另一个客户端播放同一集：如均出现问题，则属于资源问题；如仅在某个客户端出现问题，通常是客户端设置所致，请先参阅[播放问题排查](/troubleshooting/playback/)。
</Aside>

## 跟踪处理进度

反馈列表顶部可切换两个视图：

- **全部反馈**：所有用户最近提交的求片（不显示提交者），提交前可先在此确认是否已有人请求同一部影片
- **我的反馈**：您本人提交的求片和报错；报错仅在此处显示

| 状态 | 含义 |
| --- | --- |
| 等待处理 | 已收到，正在排队 |
| 寻找资源 | 正在寻找合适的版本 |
| 资源下载中 | 已找到资源，正在入库 |
| 处理完成 | 已上架或已修复，标题将显示删除线 |
| 处理异常 | 暂时无法处理，请查看管理员回复 |

点击任意一条反馈，可查看详情和**管理员回复**。求片资源入库后，状态会自动变为「处理完成」。状态变化目前不会发送邮件通知，请返回此页面查看。

## 常见问题

**新上映的影片为何长时间未上架？** 需等待高清资源发布后才能入库，此类请求的处理周期较长。

**追更剧集多长时间更新一集？** 热门剧集通常会在资源发布后尽快入库。如长时间未更新，请提交一条错误反馈告知我们。

**同一部影片是否需要重复提交？** 无需重复提交。请先在「全部反馈」中查看，如已有人请求，请等待其处理完成。
