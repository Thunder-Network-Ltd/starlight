片库里没有想看的影片，或者片源有缺集、无法播放、字幕不对等问题，都在控制台的 **[求片与反馈](https://www.lumen.ax/dashboard/feedback)** 中处理。影片上线、问题处理完成后，我们会发邮件通知您。充值、订阅和账号问题请[联系客服](/panel/support/)。

## 搜索

在搜索框中输入片名或原名，也可以直接粘贴 [TMDB](https://www.themoviedb.org/) 或[豆瓣](https://movie.douban.com/)的详情页链接。同名影片较多时，粘贴链接可以准确定位到您要的那一部。每条结果都会标明它在片库中的情况：

| 标记 | 含义 | 可以做什么 |
| --- | --- | --- |
| **已上线** | 片库中已有 | **观看**，或 **反馈问题** |
| **暂未上线** | 片库中没有，也还没有人求过 | **求片** |
| **N 人想看** | 已有人求片，并显示当前进度 | **我也想看** |
| **暂不收录** | 暂不收录这部影片，并注明原因 | — |

在[在线观影](/watch/web/)中搜不到影片时，结果页的 **提交求片** 会带着片名跳到这里。

## 求片

<Steps>

1. 在搜索结果中找到标记为「暂未上线」的影片，点击 **求片**。

2. 剧集需要选择想看的季（至少一季）。「补充说明」可以注明版本、字幕等偏好，选填。

3. 提交后，求片会出现在 **我的求片** 中。

</Steps>

已经有人求过的影片无需重复提交，点击 **我也想看** 即可，上线时您同样会收到通知。粘贴豆瓣链接后提示「未能识别该作品」时，填写片名后点击 **按链接提交求片**，由我们人工核实。

### 处理进度

「我的求片」用进度条显示每条求片走到了哪一步：

| 状态 | 含义 |
| --- | --- |
| **已提交** | 等待处理 |
| **寻找片源** | 正在寻找合适的版本 |
| **准备上线** | 已找到片源，即将上线 |
| **已上线** | 可以观看了，点击 **观看** 进入详情页 |
| **暂无片源** | 暂时没有合适的片源；求片会保留，有片源后继续处理 |
| **暂不收录** | 不收录这部影片，并注明原因 |

新上映的影片需要等高清片源发布后才能上线，处理周期会长一些。尚未上线的求片可以 **取消求片**，取消后上线时不再通知您。

## 反馈片源问题

片库中已有的影片有问题时，从以下任一入口反馈：

- 在搜索结果中找到该影片，点击 **反馈问题**
- 在[在线观影](/watch/web/)的详情页点击 **反馈问题** 图标；剧集也可以在某一集的菜单中选择 **反馈本集问题**

反馈时选择问题范围和类型：

- **范围**：电影为整部；剧集可以选整部、某一季、某一集，也可以填写集数范围。
- **类型**：缺集或缺季、播放失败或卡顿、画质或版本、字幕、音轨、信息错误、其他。

如果已经有人反馈过同一个问题，窗口中会列出来，点击 **我也遇到了** 即可加入，处理完成后您会一起收到结果。

### 处理结果

**我的反馈** 列出您提交或加入的反馈，状态分为待处理、处理中、已解决和不处理，已解决与不处理都会附上说明。处理过程中可以在反馈下方补充说明；问题仍然存在时，点击 **问题仍未解决** 重新打开。

## 通知

求片上线、反馈标记为已解决时，会发邮件到您的注册邮箱；有新进展时，对应标签上也会出现红点。不需要邮件时，可以在[账号设置](/panel/account/#邮件通知)中关闭「求片与反馈」。
