求片与片源问题均在控制台的 **[求片与反馈](https://www.lumen.ax/dashboard/feedback)** 页面处理。页面顶部有四个标签：

| 标签 | 内容 |
| --- | --- |
| **搜索** | 搜索影片与剧集，对搜索结果提交求片或反馈问题 |
| **我的求片** | 您提交的求片及其处理进度 |
| **我的反馈** | 您提交的片源问题及处理结果 |
| **热门求片** | 当前想看人数最多的求片 |

<Aside type="note">
	充值、订阅、返利提现与账号问题不在此页处理，请前往[联系客服](/panel/support/)提交工单。
</Aside>

## 搜索

在搜索框中输入片名或原名，也可以直接粘贴 [TMDB](https://www.themoviedb.org/) 或[豆瓣](https://movie.douban.com/)的详情页链接。同名影片较多时，粘贴链接可以准确定位到您需要的那一部。

每条搜索结果会标明该影片在片库中的情况，并给出对应的操作：

| 结果标记 | 含义 | 可进行的操作 |
| --- | --- | --- |
| 已上线 | 片库中已有该影片 | **观看**，或点击 **反馈问题** |
| 暂未上线 | 片库中没有，也尚无人求片 | **求片** |
| N 人想看 | 已有人提交求片，并显示当前进度 | **我也想看** |
| 暂不收录 | 该影片暂不收录，并注明原因 | — |

在[在线观影](/watch/web/)中搜索不到影片时，结果页的 **提交求片** 按钮会带着片名跳转到此页并直接搜索。

## 求片

<Steps>

1. 在「搜索」中找到标记为「暂未上线」的影片，点击 **求片**。

2. 剧集需选择所需的季（至少选择一季）。「补充说明」为选填项，可注明版本、字幕等偏好。

3. 提交后，该求片会出现在「我的求片」中。

</Steps>

已有人求片的影片无需重复提交，点击 **我也想看** 即可，影片上线后您同样会收到通知。

如粘贴豆瓣链接后提示「未能识别该作品」，可填写片名并点击 **按链接提交求片**，由我们人工核实。

### 处理进度

「我的求片」以「已提交 → 寻找片源 → 准备上线 → 已上线」四步进度条显示每条求片的处理进度：

| 状态 | 含义 |
| --- | --- |
| 已提交 | 已提交，等待处理（搜索结果中显示为「待处理」） |
| 寻找片源 | 正在寻找合适的版本 |
| 准备上线 | 已找到片源，即将上线 |
| 已上线 | 影片已可观看，点击 **观看** 进入详情页 |
| 暂无片源 | 进度停在第二步并标为「暂无片源」：暂时没有合适的片源；求片会保留，有片源后继续处理 |
| 暂不收录 | 不显示进度条，标注「暂不收录」并注明原因 |

尚未上线的求片可点击 **取消求片**。取消后，该影片上线时不再通知您。

## 反馈片源问题

片库中已有的影片存在问题时，可通过以下任一入口反馈：

- 在「搜索」中找到该影片，点击 **反馈问题**
- 在[在线观影](/watch/web/)的影片详情页点击 **反馈问题** 图标；剧集也可在某一集的菜单中选择 **反馈本集问题**

反馈时请选择问题范围与问题类型，「补充说明」为选填项：

- **问题范围**：电影为整部；剧集可选择整部或某一季，选择季后可再选择整季或其中某一集，也可以在「具体集数」中填写集数范围
- **问题类型**：缺集 / 缺季（仅剧集）、播放失败或卡顿、画质或版本、字幕、音轨、信息错误、其他

如已有人反馈过同一问题，窗口中会列出该反馈。点击 **我也遇到了** 即可加入，处理完成后您会同步收到结果。

<Aside type="note" title="区分片源问题与播放问题">
	请使用另一个客户端播放同一集：如均出现问题，则属于片源问题；如仅在某个客户端出现问题，通常是客户端设置所致，请先参阅[播放问题排查](/troubleshooting/playback/)。
</Aside>

### 处理结果

「我的反馈」列出您提交或加入的反馈，以及处理回复：

| 状态 | 含义 |
| --- | --- |
| 待处理 | 已提交，等待处理 |
| 处理中 | 正在处理 |
| 已解决 | 问题已处理，并附有处理结果 |
| 不处理 | 暂不处理，并附有说明 |

处理过程中，可在该条反馈下方发送补充说明。反馈结束后如问题仍然存在，点击 **问题仍未解决** 可重新打开。

## 通知

- 求片的影片上线、反馈标记为「已解决」时，系统会向您的注册邮箱发送邮件（标记为「不处理」或「暂不收录」时不发送）。如不需要，可在[账号设置](/panel/account/#求片与反馈)的「邮件通知」中关闭「求片与反馈」
- 有新进展时，对应标签上会显示红点，个人概览的「求片与反馈」卡片也会提示

## 常见问题

**新上映的影片为何长时间未上线？** 需等待高清片源发布后才能上线，此类求片的处理周期较长。

**追更的剧集长时间未更新怎么办？** 请在该剧的详情页点击 **反馈问题**，问题类型选择「缺集 / 缺季」。

**同一部影片是否需要重复提交？** 无需重复提交。搜索结果会显示已有多少人想看，点击 **我也想看** 即可。
