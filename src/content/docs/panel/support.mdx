充值与订单、订阅、返利提现及账号相关问题，请在控制台的 **[联系客服](https://www.lumen.ax/dashboard/support)** 页面提交工单。客服的回复会显示在工单对话中，并通过邮件通知您。

<Aside type="note">
	求片与片源问题（缺集、无法播放、字幕等）请在[求片与反馈](/panel/feedback/)中提交。
</Aside>

## 提交工单

<Steps>

1. 点击右上角的 **新建工单**，选择问题分类：充值与订单、订阅、返利提现、账号与登录或其他。

2. 填写标题和详细说明，请写明问题经过及期望的处理方式。

3. 分类为「充值与订单」时，可在「关联订单」中选择相关订单，便于客服核实。

4. 如有需要，可添加截图（最多 3 张，支持 PNG、JPEG、WebP 格式），然后点击 **提交**。

</Steps>

以下入口会直接打开新建工单窗口，并带入相关信息：

- **充值记录、订阅记录**：每笔订单右侧的 **联系客服**，自动关联该订单
- **邀请返利**：返利余额达到提现门槛后显示的 **申请提现**

## 查看回复

工单列表显示每张工单的状态，点击即可查看完整对话并继续回复。回复中同样可以添加截图。

| 状态 | 含义 |
| --- | --- |
| 待客服回复 | 已提交或已回复，等待客服处理 |
| 待你回复 | 客服已回复，等待您补充信息或确认 |
| 已关闭 | 问题已处理完毕 |

- 客服回复后，系统会向您的注册邮箱发送邮件；此类邮件不受「邮件通知」开关影响
- 有新回复时，侧栏的「联系客服」会显示未读提示
- 工单关闭后如问题仍未解决，可在该工单中点击 **重新打开**
