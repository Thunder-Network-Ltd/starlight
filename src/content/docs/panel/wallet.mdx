在 Lumen，所有费用均通过**钱包**结算：先充值到钱包，再从钱包余额中扣除。购买套餐、续费和创建兑换码均使用余额支付。

## 余额充值

请在 **[余额充值](https://www.lumen.ax/dashboard/wallet)** 页面进行操作：

<Steps>

1. 选择充值金额：¥10 / ¥30 / ¥50 / ¥100，或输入自定义金额（**最低 5 元**）。

2. 选择支付方式：**支付宝**或**微信**。

3. 核对「应付金额」。支付通道会收取少量手续费，页面会分别列出基础金额和手续费。

4. 点击 **确认充值**，页面将弹出二维码：
   - 在电脑上：使用手机支付宝 / 微信扫码
   - 在手机上：点击「打开支付页面」直接跳转支付

5. 支付完成后，弹窗显示「支付成功，余额已更新」，余额即时到账。

</Steps>

<Aside type="caution" title="订单有效期为 10 分钟">
	二维码弹窗上显示倒计时。**订单失效后请勿再付款**，重新创建订单即可。
	如已付款但余额未到账，也请勿重复支付，请按[充值未到账](/troubleshooting/billing/#充值已扣款但余额未到账)中的说明处理。
</Aside>

### 继续支付与充值记录

如已关闭支付弹窗，请在页面下方的**充值记录**中找到状态为「待支付」的订单，点击 **继续支付** 即可重新打开二维码，前提是该订单尚未过期。

充值记录会列出每一笔订单的状态（待支付 / 已支付 / 已失败 / 已过期）、到账金额、应付金额和订单号。

## 兑换码

**[兑换码](https://www.lumen.ax/dashboard/redeem)** 用于在账号之间转移余额，例如将一个月会员的费用赠送给朋友。兑换码仅代表一笔余额，**不直接绑定套餐**，对方兑换后可自行购买所需的套餐。

### 创建兑换码

1. 在「创建兑换码」中输入金额（从您的余额中扣除）
2. 确认后将生成一个 16 位的兑换码，可在下方的「兑换码列表」中复制
3. 将兑换码发送给对方

**创建后不可撤销**，金额会立即从您的余额中扣除。

### 使用兑换码

1. 在「使用兑换码」中粘贴兑换码（不区分大小写）
2. 页面会先进行校验，并在确认弹窗中显示金额
3. 确认后，金额将存入您的余额

规则：

- 每个兑换码仅可使用一次，不设过期时间
- 不能兑换自己创建的兑换码
- 如提示「兑换码无效」，请检查兑换码是否复制完整，或该兑换码是否已被他人使用

<Aside type="danger">
	请仅接受朋友或官方活动发放的兑换码。**请勿通过任何非官方渠道购买兑换码**，因受骗损失的余额无法追回。
</Aside>

### 查看兑换码状态

「兑换码列表」显示您创建过的所有兑换码，包括金额和状态（可使用 / 已使用）；已使用的兑换码还会显示兑换者的邮箱和兑换时间。
