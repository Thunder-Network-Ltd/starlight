所有订阅操作均在控制台的 **[服务订阅](https://www.lumen.ax/dashboard/subscription)** 页面完成。订阅费用一律从**钱包余额**中扣除，如余额不足，请先[充值](/panel/wallet/)。

## 购买套餐

<Steps>

1. 在「购买 / 续费」区域选择计费周期。目前仅开放**按月支付**，按年支付暂未开放。

2. 选择一个套餐卡片，点击 **选择并订阅**。每个套餐包含的线路和流量均标注在卡片上，对比说明请参阅[套餐、线路与流量](/start/plans/)。

3. 在确认弹窗中核对金额。如有折扣码，请填写在「折扣码」一栏，弹窗会实时计算折后价格。余额不足时，弹窗会显示差额，按钮变为 **余额不足，去充值**。

4. 点击 **确认并支付**。费用将从余额中扣除，订阅立即生效，有效期自当前时间起计算 1 个月，客户端即可登录。

5. 订阅生效后，点击页面上的 **查看播放线路**，即可查看线路地址并在客户端中登录。

</Steps>

<Aside type="note">
	部分套餐名额有限，卡片上会显示「仅剩 N 个名额」或「已售罄」。已售罄的套餐无法新购，但**订阅仍在有效期内的用户可以续费该套餐**。订阅到期后重新购买按新购处理，同样受名额限制。
</Aside>

## 续费、升级与更换套餐

同一个按钮会根据您当前的订阅执行不同的逻辑：

| 操作 | 规则 |
| --- | --- |
| **续费同一套餐** | 到期时间自**原到期日**起顺延 1 个月，剩余天数不会损失；当前周期的已用流量不变 |
| **升级到价格更高的套餐** | 当前订阅的剩余时间折算后抵扣，补足差价即可；新套餐自当前时间起计算 1 个月，流量重新计算 |
| **更换为同价或价格更低的套餐** | 不支持。需待当前套餐到期后再购买 |

升级的折算方式为：`抵扣金额 = 当前订阅有效期内的已付金额 × 剩余天数 ÷ 有效期总天数`。已付金额按实际支付计算，使用折扣码的按折后金额计；确认弹窗中的「剩余时间折算」一行会直接显示抵扣金额。

### 续费、升级后的流量

流量按计费周期计算：自订阅生效时起，每一个月为一个周期，每个周期一份流量额度。

- **新购、升级，以及到期后的续订（包括自动续订）**：从当时起开始新的周期，已用流量从 0 重新计算
- **在有效期内提前续费同一套餐**：只顺延到期日，当前周期的已用流量不变；顺延的月份各有一份额度

流量的计算方式与用完后的处理，详见[套餐、线路与流量](/start/plans/#流量)。

## 折扣码

折扣码仅在购买套餐时使用，请填写在确认弹窗的「折扣码」一栏（不区分大小写）。常见提示如下：

| 提示 | 原因 |
| --- | --- |
| 折扣码不存在或已失效 | 输入有误，或折扣码已被停用 |
| 折扣码不适用于当前套餐 | 该折扣码仅限用于其他套餐 |
| 折扣码已过期 / 已达到使用上限 / 已被使用 | 折扣码本身的使用限制 |

<Aside type="tip">
	折扣码（购买套餐时享受折扣）与[兑换码](/panel/wallet/#兑换码)（用于转移余额）用途不同，请勿填错位置。
</Aside>

## 自动续订

「当前订阅」区域提供 **自动续订** 开关。开启后，订阅到期时将自动从钱包余额扣费并续期一个月。

- **首次订阅默认开启**，确认弹窗中会注明「到期后自动续订，可随时关闭」
- 订阅到期后重新订阅的，自动续订保持关闭，如需要请重新开启
- 自动续订按扣款当天的套餐价格从余额扣费。折扣码仅对使用的那一次购买有效，不适用于之后的自动续订
- 套餐停止销售后，已有订阅的自动续订不受影响

| 到期时的状态 | 结果 |
| --- | --- |
| 已开启自动续订，余额充足 | 自动扣费，服务不中断 |
| 已开启自动续订，余额不足 | 续订不成功，播放**立即暂停**，订阅状态显示为「续订未成功」 |
| 未开启自动续订 | 到期后立即暂停 |

续订不成功后，充值并在本页重新购买即可恢复播放。在 1 天内完成的，自动续订保持开启；超过 1 天后订阅转为「已到期」，自动续订随之关闭。

<Aside type="caution" title="保持余额充足">
	自动续订扣款失败后不会自动重试。为避免观看过程中服务被暂停，建议在到期前确认余额足以支付一个月的费用。
</Aside>

## 到期与续订的提醒邮件

如您已在[账号设置](/panel/account/#提醒邮件)中开启「提醒邮件」，将会收到以下邮件：

- **未开启自动续订**：到期前 1–3 天及到期当天，各提醒一次
- **已开启自动续订**：到期前 3 天发送续订预告，列明套餐、到期时间、将扣金额与当前余额；余额不足时会提醒您充值
- **自动续订扣款成功**：发送扣款回执，列明扣款金额与新的到期时间
- **自动续订失败**：通知您服务已暂停

## 订阅到期之后

订阅到期后，播放权限将被暂停，客户端无法登录和播放。**观看记录、收藏和播放进度均会保留**，重新订阅后立即恢复；如客户端提示登录失效，重新登录即可。

到期后重新购买按新购处理：有效期自购买时起计算，名额有限的套餐需仍有名额方可购买。

## 订阅记录

页面底部的「订阅记录」列出每一笔订阅扣款，支持按状态筛选和按订单号搜索。如对某笔扣款有疑问，点击该订单右侧的 **联系客服**，即可就该订单[提交工单](/panel/support/)。
