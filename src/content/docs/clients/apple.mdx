SenPlayer、Infuse、Rex 都支持 iPhone、iPad、Mac 和 Apple TV。经常观看 HDR、杜比视界内容或使用 Vision Pro，适合 Infuse；想看弹幕，SenPlayer 与 Rex 会自动加载。线路地址与账号见[连接信息](/clients/connect/)。

## SenPlayer

从 [App Store](https://apps.apple.com/us/app/senplayer-media-player/id6443975850) 下载，付费。Windows 与 Android 版正在开发中，推出后补充教程。

<Steps>

1. 打开底部的 **资源库**，点击右上角的 **+**。

2. 选择 **Emby**。

3. 填写以下内容，点击右上角的 **保存**：

   <Fields
   	rows={[
   		['名称', '任意，例如 `Lumen`'],
   		['主机', '线路域名，**不含** `https://`'],
   		['端口', '`443`'],
   		['https', '**打开**'],
   		['用户 / 密码', 'Lumen 用户名（或邮箱）和密码'],
   	]}
   />

</Steps>

## Infuse

从[官网](https://firecore.com/infuse)或 App Store 下载，部分功能需订阅 Infuse Pro。

<Steps>

1. 打开底部的 **设置**，点击 **新增文件来源**。

2. 在「已储存的共享」下点击 **添加…**。

3. 选择 **添加 Emby**（不要选 Emby Connect 或 Jellyfin）。

4. 填写以下内容，点击底部的 **新增**：

   <Fields
   	rows={[
   		['名称', '任意，例如 `Lumen`'],
   		['位址', '线路域名，**不含** `https://`'],
   		['用户名 / 密码', 'Lumen 用户名（或邮箱）和密码'],
   		['高级 → 端口', '`443`'],
   		['高级 → HTTPS', '自动'],
   		['高级 → 媒体库模式', '**关闭**（开启后会把整个片库扫描到本地，首次很慢）'],
   	]}
   />

</Steps>

## Rex

Forward 团队的新作（Forward 已下架）。从 [App Store](https://apps.apple.com/cn/app/id6801583759) 免费下载，App 内订阅或买断。

<Steps>

1. 打开底部的 **资源库**，点击 **添加资源库**。

2. 选择 **Emby**。

3. 在「连接」页填写以下内容，点击右上角的 **保存**：

   <Fields
   	rows={[
   		['连接地址', '线路域名，**不含** `https://`'],
   		['端口', '`443`（冒号后那一格）'],
   		['路径', '留空'],
   		['开启 HTTPS', '**打开**'],
   		['用户名 / 密码', 'Lumen 用户名（或邮箱）和密码'],
   	]}
   />

4. （可选）保存前切到 **线路** 页，打开 **自动同步线路**，套餐中的其他线路会作为备用服务器加入。

</Steps>
