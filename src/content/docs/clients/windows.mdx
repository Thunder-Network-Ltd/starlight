Windows 上可以使用小幻影视或 Hills Lite，SenPlayer 的 Windows 版正在开发中。Mac 上可以直接使用 [SenPlayer](/clients/apple/#senplayer)、[Infuse](/clients/apple/#infuse) 等 Apple 版客户端。偶尔观看也可以用控制台的[在线观影](/watch/web/)。线路地址与账号见[连接信息](/clients/connect/)。

## 小幻影视

从[微软商店](https://apps.microsoft.com/detail/9nb0h051m4v4)下载，付费。

<Steps>

1. 在左侧「服务列表」中点击 **+**，选择 **Emby**。

2. 填写显示名称、服务器地址（完整线路地址）、Lumen 用户名（或邮箱）和密码。

3. 点击 **测试连接**，通过后点击 **创建**。

</Steps>

## Hills Lite

从[微软商店](https://apps.microsoft.com/detail/9nxnzfrllwzx)下载，付费。添加服务器时选择 **Emby**，填写完整线路地址（包含 `https://`）、端口 `443` 以及 Lumen 用户名（或邮箱）和密码，步骤与 [Android 版 Hills](/clients/android/#hills) 相同。

## Emby 官方客户端

也可以使用 Emby 官方的 Windows 客户端，登录时手动输入用户名和密码。
