## 如何选择客户端

选择客户端时，最重要的是**解码能力**。Lumen 的服务器**不进行转码**，向您发送的是原始文件，能否流畅播放完全取决于客户端和设备本身：

- 如果您经常观看 **4K HDR、杜比视界** 内容，请选择支持硬件解码和 HDR 输出的客户端，例如 Apple 设备上的 Infuse、Android 设备上的 Hills
- 如果 **TrueHD、DTS-HD** 音轨没有声音，请更换支持软件解码这些格式的客户端，或关闭音频直通
- 如果某部影片在当前客户端中无法播放，更换其他客户端通常即可解决

:::tip[在浏览器中观看]
通过控制台的[在线观影](/watch/web/)，您可以直接在浏览器中观看，适合临时使用。长期观看时，客户端的播放体验更好。
:::
