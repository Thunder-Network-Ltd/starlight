弹幕来自各视频平台的公开弹幕，播放时实时获取，站内不存储。网页播放器自动匹配；第三方播放器填一次专属地址即可。

## 网页播放器

播放时点右下角的「弹」按钮即可打开或关闭弹幕。更多设置在齿轮菜单最前面的「弹幕」分组里：

| 设置 | 说明 |
| --- | --- |
| 不透明度 | 弹幕整体的透明程度 |
| 字号 | 小、中、大 |
| 速度 | 滚动弹幕横穿画面的快慢 |
| 显示区域 | 只占顶部四分之一、上半屏或全屏 |
| 顶部与底部弹幕 | 不想看固定在顶部、底部的弹幕时关掉 |
| 时间偏移 | 弹幕比画面快就往后拨，慢就往前拨，半秒一档 |

这些设置记在当前浏览器里，换设备要重新设。

### 匹配错了怎么办

齿轮菜单的「弹幕」分组会写明当前匹配到的作品和集数。对不上时点「换一个」，从候选里选正确的作品；选择会按剧记住，这部剧之后的每一集都按它找。

<Aside type="tip">
	看到「弹幕来源的片长和这个文件差得比较多」的提示，多半是弹幕来源那边是剪辑版或合集，可以试试「换一个」或调时间偏移。
</Aside>

## 第三方播放器

Yamby、Hills、SenPlayer、Forward、ChaiChai、afusekt 等支持「自定义弹幕 API」的播放器都能用。

1. 打开控制台 → [账号设置](/panel/account/) → 弹幕，复制「弹幕地址」。
2. 在播放器的弹幕设置里选择自定义弹幕 API，粘贴这条地址。
3. 播放时打开弹幕即可；不同播放器的入口名称略有差异，一般在播放界面的弹幕按钮里。

<Aside type="caution">
	这条地址是您专属的，不要分享给别人。怀疑泄露时在账号设置里点「重置地址」，旧地址立即失效，所有填了旧地址的播放器都要重新填一次。
</Aside>

地址里的域名是您的任一播放线路，填哪条都可以。

## 哪些内容没有弹幕

- 国内视频平台没有正版上线的内容（多数海外剧集、部分动画）没有弹幕来源。
- 刚更新的集数，平台那边的弹幕要过一阵才有。
- 同一部作品在不同平台弹幕量差别很大，自动匹配会优先选弹幕多、年份和集数都对得上的那个。

## 常见问题

**弹幕和画面对不上几秒。** 在网页播放器用「时间偏移」微调；第三方播放器一般也有类似的偏移设置。

**整集都没有弹幕，但别的集有。** 多半是这一集在平台那边被拆成了预告或合集，用「换一个」或等平台更新。

**第三方播放器提示地址无效。** 核对是否完整复制、有没有多余空格；地址被重置过的话要重新复制。
