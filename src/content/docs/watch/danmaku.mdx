弹幕来自各视频平台的公开弹幕，播放时实时获取，站内不存储。网页播放器自动匹配；第三方播放器填写一次专属地址即可使用。

## 网页播放器

控制栏上有两个弹幕按钮：气泡图标用于开关弹幕（键盘快捷键 <kbd>D</kbd>）；「弹幕设置」按钮打开以下设置（在电脑上将鼠标悬停于按钮上也会展开），齿轮菜单末行的「弹幕设置…」同样可以进入。

| 设置 | 说明 |
| --- | --- |
| 不透明度 | 弹幕整体的透明程度 |
| 字号 | 小、中、大 |
| 速度 | 滚动弹幕横穿画面的快慢 |
| 显示区域 | 顶部四分之一、半屏、四分之三（默认）或全屏 |
| 防挡字幕 | 默认开启：画面底部留给字幕，弹幕不进入该区域 |
| 屏蔽类型 | 分别关闭顶部、底部或彩色弹幕 |
| 屏蔽词 | 包含这些词的弹幕不显示；也可写成 `/正则/` |
| 时间偏移 | 弹幕早于画面时调大偏移，晚于画面时调小，每档半秒 |

这些设置保存在当前浏览器中，更换设备后需重新设置。视频暂停或缓冲时，弹幕同步暂停。

### 匹配有误时

弹幕设置的第一行显示当前匹配到的作品与集数。匹配有误时，点击「更换」从候选中选择正确的作品；该选择按剧集的当前季记住，之后各集按此匹配。如需恢复自动匹配，点击「恢复自动匹配」。

<Aside type="tip">
	出现「弹幕来源的片长与当前文件差异较大」提示时，弹幕来源可能是剪辑版或合集，可尝试「更换」或调整时间偏移。
</Aside>

## 第三方播放器

SenPlayer、Rex 在播放时会自动加载弹幕，通常无需设置；未显示弹幕时，再按以下方法填写地址。

Yamby、Hills、SenPlayer、ChaiChai、AfuseKt 等支持「自定义弹幕 API」的播放器均可使用。

1. 打开控制台 → [账号设置](/panel/account/) → 弹幕，复制「弹幕地址」。
2. 在播放器的弹幕设置中选择自定义弹幕 API，粘贴该地址。
3. 播放时开启弹幕即可；各播放器的入口名称略有差异，通常位于播放界面的弹幕按钮中。

<Aside type="caution">
	该地址为您专属，请勿分享给他人。如怀疑泄露，可在账号设置中点击「重置地址」；原地址将立即失效，已填写原地址的播放器需重新填写。
</Aside>

地址中的域名为您的任一播放线路，均可使用。

## 没有弹幕的内容

- 国内视频平台未上线的内容（多数海外剧集、部分动画）没有弹幕来源。
- 刚更新的集数，平台的弹幕需要一段时间后才会出现。
- 同一部作品在各平台的弹幕量差异较大，自动匹配优先选择弹幕较多、年份与集数均相符的来源。

## 常见问题

**弹幕与画面相差几秒。** 可在网页播放器的「时间偏移」中微调；第三方播放器通常也有类似设置。

**某一集没有弹幕，其他集正常。** 可能是该集在平台上被拆分为预告或合集，可点击「更换」重新匹配，或等待平台更新。

**网页播放器提示「暂时无法获取」。** 请点击弹幕设置中的「重试」；仍无法获取时，请稍后再试。

**第三方播放器提示地址无效。** 请核对地址是否完整、有无多余空格；地址重置后需重新复制。
