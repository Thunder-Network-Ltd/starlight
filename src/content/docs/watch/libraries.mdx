把片库整理成您自己的样子：调整媒体库的顺序、隐藏用不上的媒体库，或者按条件和榜单建立专属媒体库，例如「豆瓣 Top250」「本季新番」「周星驰作品」。建好的媒体库会像普通媒体库一样出现在所有客户端和网页中，并随片库和榜单自动更新。

这些设置都在控制台的 **[我的媒体库](https://www.lumen.ax/dashboard/virtual-libraries)** 中完成，保存在您的账号里，不需要在每个客户端中分别设置。

![控制台「我的媒体库」页面：右上角为「排序与隐藏」与「新建自定义媒体库」按钮，下方为已创建的自定义媒体库](../../../assets/panel/libraries-overview.jpg)

## 排序与隐藏

<Steps>

1. 点击 **排序与隐藏**。

2. 拖动封面调整顺序；点击封面左上角的眼睛图标，可以隐藏或重新显示该媒体库。更改会自动保存。

3. 点击 **完成**。需要恢复默认排列时，点击 **恢复默认顺序**。

</Steps>

客户端刷新后即会按新的顺序显示。隐藏的媒体库不会出现在媒体库列表中，但其中的影片仍然可以搜索和播放；它们列在页面下方的 **已隐藏** 中，随时可以恢复。

## 自定义媒体库

自定义媒体库按您设定的条件，从片库中自动挑选影片。片库新增了符合条件的影片时，它会自动更新；使用榜单时，按您设定的频率同步榜单。

- 只收录片库中已有的影片。榜单上还没有入库的影片不会出现，需要时可以[提交求片](/panel/feedback/)。
- 每个账号最多可以创建 5 个自定义媒体库，页面上会显示还能创建的数量。

### 创建媒体库

<Steps>

1. 点击 **新建自定义媒体库**，填写名称，并选择内容类型：电影与剧集、电影或剧集。

2. 在「收录规则」中选择媒体库范围。默认为全部媒体库，也可以只选其中几个。

3. 点击 **+ 条件**，逐条设置筛选条件。可用的条件有两类：
   - **榜单**：豆瓣、TMDB、Bangumi、巴哈姆特、IMDb 等榜单，以及「本站」分组中的「本周热门」「本月热门」
   - **影片信息**：类型、主题、出品地区、语言、人物、出品公司、上映（首播）时间、TMDB 评分、评分人数、分级、播出状态等

4. 需要时，在「手动调整」中指定 **始终包含** 或 **始终排除** 的影片。

5. 窗口右侧的预览会显示预计收录的数量和部分影片。确认无误后，点击 **创建**。

</Steps>

<Aside type="tip">
	首次使用某个豆瓣榜单时，预览可能需要等待几十秒，之后会快很多。
</Aside>

### 条件如何组合

- **不同条件之间需要同时满足**。例如「出品地区包含韩国」和「TMDB 评分不低于 8」，只收录同时符合两者的影片。
- **同一个条件里填写多项时，满足其中之一即可**。例如类型同时填写「动画」和「家庭」，或在一个榜单条件中添加多个榜单。
- 每个条件都可以切换比较方式，例如「包含 / 不包含」「在 / 不在」「不低于 / 不高于」。
- 需要「满足其中一组即可」时，点击 **+ 条件组**：组内的条件需要同时满足，符合任意一组的影片都会被收录。
- 「始终包含」的影片不受范围和条件限制；「始终排除」优先于其他所有设置。

## 常用示例

一两个条件就能完成的常见媒体库：

| 媒体库 | 设置方法 |
| --- | --- |
| **豆瓣 Top250** | 内容类型选「电影」；添加「榜单」条件，选择「豆瓣电影 Top250」 |
| **本季新番** | 添加「榜单」条件，选择「Bangumi 当季新番」 |
| **本月热门** | 添加「榜单」条件，在「本站」分组中选择「本月热门」 |
| **高分韩剧** | 内容类型选「剧集」；添加「出品地区」条件选「韩国」，再添加「TMDB 评分」条件，不低于 8 |

## 进阶示例

### 周星驰作品

收录片库中周星驰参演或执导的全部电影，并在封面上显示英文名。

| 设置项 | 填写内容 |
| --- | --- |
| 名称 | 周星驰作品 |
| 内容类型 | 电影 |
| 筛选条件 | 「人物」包含「周星驰」 |
| 封面副标题 | Stephen Chow |

### 高分华语悬疑剧

收录评分较高的华语悬疑剧。四个条件需要**同时满足**。

| 设置项 | 填写内容 |
| --- | --- |
| 名称 | 高分华语悬疑剧 |
| 内容类型 | 剧集 |
| 条件 1 | 「出品地区」包含「大陆」「香港」「台湾」 |
| 条件 2 | 「类型」包含「悬疑」 |
| 条件 3 | 「TMDB 评分」不低于 7.5 |
| 条件 4 | 「评分人数」不低于 100 |

出品地区中填了三项，属于其中任一地区即可；四个条件之间则需要同时满足。窗口右侧的预览会显示每加一个条件后的数量。

### 流媒体平台新剧

汇总多个流媒体平台的最新剧集：只用一个榜单条件，在其中添加四个榜单。

| 设置项 | 填写内容 |
| --- | --- |
| 名称 | 平台新剧 |
| 内容类型 | 剧集 |
| 筛选条件 | 「榜单」：依次添加「Netflix 最新剧集」「HBO 最新剧集」「Disney+ 最新剧集」「Prime Video 最新剧集」 |
| 榜单更新频率 | 每 6 小时 |

出现在任一榜单中的剧集都会被收录；榜单更新后，媒体库会随之更新。

### 合家欢动画

收录评分较高的动画与家庭影片，并排除不适合全家观看的类型。

| 设置项 | 填写内容 |
| --- | --- |
| 名称 | 合家欢 |
| 内容类型 | 电影 |
| 条件 1 | 「类型」包含「动画」「家庭」 |
| 条件 2 | 「TMDB 评分」不低于 7 |
| 条件 3 | 「类型」不包含「恐怖」 |

类型为动画**或**家庭的影片都会被收录，其中类型含恐怖的会被排除。

### 本季追番

同时收录当季新番榜上的动画，以及仍在连载的日本剧集。这里使用两个**条件组**，符合任意一组即可。

| 设置项 | 填写内容 |
| --- | --- |
| 名称 | 本季追番 |
| 内容类型 | 剧集 |
| 条件组 1 | 「榜单」在「Bangumi 当季新番」 |
| 条件组 2 | 「出品地区」包含「日本」；「播出状态」选择「连载中」 |

### 个人片单

不设置筛选条件，只收录您亲自挑选的影片，适合整理「想看清单」或专题片单。

| 设置项 | 填写内容 |
| --- | --- |
| 名称 | 想看清单 |
| 筛选条件 | 不添加 |
| 手动调整 | 在「始终包含」中搜索片库，逐部加入 |

之后在[在线观影](/watch/web/)中浏览时，也可以随时把影片加入这个片单，见下文。

## 从详情页加入

在[在线观影](/watch/web/)中打开任意一部影片，点击详情页上的 **加入自定义媒体库** 图标，在列表中勾选要加入的媒体库；已勾选的再点一次即可移出。列表底部也可以直接新建自定义媒体库。

## 管理媒体库

点击媒体库封面右上角的菜单，可以 **编辑**、**立即更新**、**更换封面**、**隐藏** 或 **删除** 该媒体库。删除媒体库不会影响片库中的影片。
