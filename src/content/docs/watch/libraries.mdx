把片库整理成您自己的样子：调整媒体库的顺序、隐藏用不上的媒体库，或者按条件和榜单建立专属媒体库，例如「豆瓣 Top250」「本季新番」「周星驰作品」。建好的媒体库会像普通媒体库一样出现在所有客户端和网页中，并随片库和榜单自动更新。

这些设置都在控制台的 **[我的媒体库](https://www.lumen.ax/dashboard/virtual-libraries)** 中完成，保存在您的账号里，不需要在每个客户端中分别设置。

## 排序与隐藏

<Steps>

1. 点击 **排序与隐藏**。

2. 拖动封面调整顺序；点击封面左上角的眼睛图标，可以隐藏或重新显示该媒体库。更改会自动保存。

3. 点击 **完成**。需要恢复默认排列时，点击 **恢复默认顺序**。

</Steps>

客户端刷新后即会按新的顺序显示。隐藏的媒体库不会出现在媒体库列表中，但其中的影片仍然可以搜索和播放；它们列在页面下方的 **已隐藏** 中，随时可以恢复。

## 自定义媒体库

自定义媒体库按您设定的条件，从片库中自动挑选影片。片库新增了符合条件的影片时，它会自动更新；使用榜单时，按您设定的频率同步榜单。

- 只收录片库中已有的影片。榜单上还没有入库的影片不会出现，需要时可以[提交求片](/panel/feedback/)。
- 每个账号最多可以创建 5 个自定义媒体库，页面上会显示还能创建的数量。

### 创建媒体库

<Steps>

1. 点击 **新建自定义媒体库**，填写名称，并选择内容类型：电影与剧集、电影或剧集。

2. 在名称下方「在 **全部媒体库** 中」处选择范围。默认为全部媒体库，也可以只选其中几个。

3. 点击 **+ 条件**，逐条设置筛选条件。可用的条件有两类：
   - **榜单**：豆瓣、TMDB、Bangumi、巴哈姆特、IMDb 等榜单，以及「Lumen」分组中的「本周热门」「本月热门」
   - **影片信息**：类型、主题、出品地区、语言、人物、出品公司、上映（首播）时间、TMDB 评分、评分人数、分级、播出状态等

4. 需要时，在「手动调整」中指定 **始终包含** 或 **始终排除** 的影片。

5. 窗口右侧的预览会显示预计收录的数量和部分影片。确认无误后，点击 **创建**。

</Steps>

<Screenshot name="library-editor" alt="「新建自定义媒体库」窗口：名称为「高分华语悬疑剧」，内容类型为剧集，依次添加出品地区（大陆、香港、台湾）、类型（悬疑）、TMDB 评分不低于 7.5、评分人数不低于 20 四个条件，右侧预览显示 37 部符合" />

### 条件如何组合

- **不同条件之间需要同时满足**。例如「出品地区包含韩国」和「TMDB 评分不低于 8」，只收录同时符合两者的影片。
- **同一个条件里填写多项时，满足其中之一即可**。例如类型同时填写「动画」和「家庭」，或在一个榜单条件中添加多个榜单。
- 每个条件都可以切换比较方式，例如「包含 / 不包含」「在 / 不在」「不低于 / 不高于」。
- 需要「满足其中一组即可」时，点击 **+ 条件组**：组内的条件需要同时满足，符合任意一组的影片都会被收录。
- 「始终包含」的影片不受范围和条件限制；「始终排除」优先于其他所有设置。

## 常用示例

一两个条件就能完成的常见媒体库：

<RecipeGrid>
	<LibraryRecipe name="豆瓣 Top250" type="电影" rules={[{ field: '榜单', op: '在', values: ['豆瓣电影 Top250'] }]} />
	<LibraryRecipe name="本季新番" rules={[{ field: '榜单', op: '在', values: ['Bangumi 当季新番'] }]} />
	<LibraryRecipe name="本月热门" rules={[{ field: '榜单', op: '在', values: ['本月热门'] }]} />
	<LibraryRecipe
		name="高分韩剧"
		type="剧集"
		rules={[
			{ field: '出品地区', op: '包含', values: ['韩国'] },
			{ field: 'TMDB 评分', op: '不低于', value: '8' },
		]}
	/>
</RecipeGrid>

「本月热门」在榜单列表的「Lumen」分组中。

## 进阶示例

下面几个示例用到多选、排除、条件组和手动调整，可以照着填写后再按需调整。

### 周星驰作品

收录片库中周星驰参演或执导的全部电影，并在封面上显示英文名。

<LibraryRecipe
	name="周星驰作品"
	type="电影"
	rules={[{ field: '人物', op: '包含', values: ['周星驰'] }]}
	extras={[['封面副标题', 'Stephen Chow']]}
/>

### 高分华语悬疑剧

出品地区里选了三项，属于其中任一地区即可；四个条件之间需要同时满足。窗口右侧的预览会显示每加一个条件后的数量。

<LibraryRecipe
	name="高分华语悬疑剧"
	type="剧集"
	rules={[
		{ field: '出品地区', op: '包含', values: ['大陆', '香港', '台湾'] },
		{ field: '类型', op: '包含', values: ['悬疑'] },
		{ field: 'TMDB 评分', op: '不低于', value: '7.5' },
		{ field: '评分人数', op: '不低于', value: '20' },
	]}
/>

### 流媒体平台新剧

只用一个榜单条件，在其中添加四个榜单：出现在任一榜单中的剧集都会被收录，榜单更新后媒体库随之更新。

<LibraryRecipe
	name="平台新剧"
	type="剧集"
	rules={[{ field: '榜单', op: '在', values: ['Netflix 最新剧集', 'HBO 最新剧集', 'Disney+ 最新剧集', 'Prime Video 最新剧集'] }]}
	extras={[['榜单更新频率', '每 6 小时']]}
/>

### 合家欢动画

类型为动画**或**家庭的影片都会被收录，其中类型含恐怖的会被排除。

<LibraryRecipe
	name="合家欢"
	type="电影"
	rules={[
		{ field: '类型', op: '包含', values: ['动画', '家庭'] },
		{ field: 'TMDB 评分', op: '不低于', value: '7' },
		{ field: '类型', op: '不包含', values: ['恐怖'] },
	]}
/>

### 本季追番

同时收录当季新番榜上的动画，以及仍在连载的日本剧集。点击 **+ 条件组** 建两组，符合任意一组即可。

<LibraryRecipe
	name="本季追番"
	type="剧集"
	groups={[
		[{ field: '榜单', op: '在', values: ['Bangumi 当季新番'] }],
		[
			{ field: '出品地区', op: '包含', values: ['日本'] },
			{ field: '播出状态', values: ['连载中'] },
		],
	]}
/>

### 个人片单

不设筛选条件，只收录您亲自挑选的影片，适合整理想看清单或专题片单。之后在[在线观影](/watch/web/)中浏览时，也可以随时把影片加入这个片单，见下文。

## 从详情页加入

在[在线观影](/watch/web/)中打开任意一部影片，点击详情页上的 **加入自定义媒体库** 图标，在列表中勾选要加入的媒体库；已勾选的再点一次即可移出。列表底部也可以直接新建自定义媒体库。

## 管理媒体库

点击媒体库封面右上角的菜单，可以 **编辑**、**立即更新**、**更换封面**、**隐藏** 或 **删除** 该媒体库。删除媒体库不会影响片库中的影片。
