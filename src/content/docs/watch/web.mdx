控制台侧栏中的 **[在线观影](https://www.lumen.ax/dashboard/library)** 是一个在浏览器中使用的片库：无需安装任何软件，在电脑、平板或手机上打开网页即可查找和播放影片。

<Aside type="tip" title="网页播放适用于临时观看">
	网页播放器的解码能力不及客户端。如需长期观看或观看 4K 原盘，建议安装[客户端](/clients/)。
	同一账号的观看进度在网页与客户端之间同步。
</Aside>

## 查找影片

- **首页**：顶部为轮播推荐，下方依次为「继续观看」「接着追」以及各媒体库的「最新入库」；点击「查看全部」可进入完整的媒体库
- **搜索**：顶部搜索框支持中文名和原名，输入后自动显示结果
- **无搜索结果**：结果页会提示片库暂未收录，点击 **提交求片** 可直接进入[片库反馈](/panel/feedback/)

未订阅时也可浏览和搜索片库，但无法播放。

## 详情页

点击任意海报即可进入详情页：

- **播放**：未观看过的影片从头播放，已观看过的显示「继续观看 01:23:45」
- **从头开始**、**标记为已播放 / 未播放**、**收藏**
- **一起看**：与好友同步观看，详见[一起看](/watch/together/)
- **加入自定义媒体库**：将该影片加入您创建的某个媒体库，详见[我的媒体库](/watch/libraries/#从详情页加入)
- 剧集会列出季选择和每一集，未收录的集会单独标注
- 下方为演职人员和详细信息（原名、上映日期、片长、分级、类型等）；**点击演员头像**可查看其在片库中的全部作品

## 播放器

播放页为全屏显示，移动鼠标或轻点屏幕即可显示控制栏。

### 播放设置

点击控制栏中的 **播放设置**，可切换以下选项：

| 选项 | 说明 |
| --- | --- |
| **版本** | 同一影片的不同版本，例如 `2160p · H.265 · HDR10`，并显示文件大小；浏览器无法播放的版本会注明原因 |
| **线路** | 切换当前套餐中可用于网页播放的线路 |
| **倍速** | 0.5× 至 2× |
| **音轨** | 切换语言 / 音轨 |
| **字幕** | 支持 SRT、ASS/SSA、WebVTT 和 PGS 图形字幕 |

「播放信息」可查看当前视频、音频编码等技术细节。

线路不通时，播放器会自动切换到另一条线路，并提示「线路不通，正在切到……」。

## 限制

- **需要有效订阅**，且套餐中须包含可用于网页播放的线路（网页播放仅使用 HTTPS 直连线路）
- **同一账号最多可同时开启 3 个网页播放**，超出时会提示先关闭其他播放页
- 浏览器无法播放以下格式：VC-1 视频、TrueHD / 杜比全景声（TrueHD）音轨、杜比视界 Profile 5。遇到此类格式时，播放器会自动选择可播放的版本；如所有版本均无法播放，请使用客户端观看
- 在 iPhone 系统全屏模式下，不显示 PGS 图形字幕

## 处理播放错误

播放器报错时会注明原因，并提供「重试当前线路」按钮。请按以下顺序尝试：

1. 点击 **重试当前线路**
2. 在「播放设置」中更换**版本**或**线路**
3. 如仍无法播放，请改用[客户端](/clients/)播放，客户端的兼容性更好

如提示「播放许可已失效」，通常是因为您在其他设备上开启了新的播放，刷新页面即可。
