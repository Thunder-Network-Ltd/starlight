播放问题基本逃不出四类：**卡顿、字幕、画面、声音**。找到对应的现象，按步骤排查即可。

:::tip[排查前先做一件事]
在客户端的播放页面打开「播放信息 / 统计信息」，确认当前是**直接播放**还是**转码播放**。
这是判断大多数问题的关键线索：直连卡顿多半是网络或线路问题，转码则说明设备不支持当前格式。
:::

## 播放卡顿、频繁缓冲

按顺序排查，大多数卡顿在前两步就能解决：

1. **换线路对比**。到面板**个人概览**复制另一条线路地址，在客户端切换后播放同一部影片对比。明显改善就固定用新线路——不同运营商和地区适合的线路不同。
2. **检查自家网络**。优先使用 5GHz Wi-Fi 或有线连接；隔了几堵墙的 2.4GHz Wi-Fi 播 4K 一定会卡。可以先测速：4K 高码率原盘的瞬时码率可达 80–100 Mbps。
3. **查看播放信息**。如果显示正在转码，说明设备不支持该影片的格式，换一个解码能力更强的客户端（见[客户端总览](/application/summery/)）通常能转为直连。
4. **降低播放码率**。作为临时方案，在客户端播放设置里手动降低画质，先看上再说。

## 字幕问题

### 字幕乱码

字幕文件编码与客户端不匹配导致。在客户端字幕设置里调整字幕编码（选择 UTF-8 或自动检测）；部分客户端需要重进播放页生效。

### 字幕不显示或加载慢

- 确认播放页的字幕轨道已选中（有的客户端默认「无字幕」）
- 外挂字幕首次加载需要几秒，稍等片刻
- PGS / SUP 图形字幕在部分客户端上需要转码烧录，若无法显示可尝试切换 SRT / ASS 文本字幕轨道，或换客户端

### 字幕不同步

在客户端播放设置里调整「字幕偏移」；若整部影片固定快 / 慢几秒，调一次偏移即可。

## 画面问题

### 4K HDR 影片画面发灰

设备或客户端不支持 HDR，画面按 SDR 直出导致。解决：在客户端设置中开启**色调映射（Tone Mapping）**，或改用支持 HDR 的设备观看。

### 杜比视界影片偏紫 / 偏绿

客户端不支持该影片的杜比视界 Profile。选择同片的 HDR10 / SDR 版本，或换用支持杜比视界的客户端与设备。

### 画面撕裂、掉帧

电视盒子常见。在客户端设置里开启「自动切换刷新率」，让输出帧率匹配影片帧率。

## 声音问题

### 没有声音或只有杂音

影片的音轨格式（TrueHD、DTS-HD 等）不被当前设备支持。解决：

- 在播放页切换到 AAC / AC3 等兼容音轨（如有）
- 在客户端设置里关闭「音频直通（Passthrough）」，让客户端解码
- 或换用解码能力更强的客户端

### 音画不同步

先暂停再继续播放，多数客户端会重新对齐；仍不同步时在播放设置里调整「音频偏移」。

## 提示错误、完全无法播放

1. 确认订阅未到期（到期会停用 Emby 账号，续费即恢复）
2. 换一条线路再试，当前线路可能在维护
3. 换一个客户端播同一影片：如果都失败，多半是资源本身的问题

## 资源本身有问题？

如果排查后确认是资源问题（缺集、坏档、音画错误、字幕缺失），请在面板**片库反馈**提交「错误反馈」：填写媒体标题与问题描述，**剧集具体到季和集**，我们会尽快修复。

登录类问题见[账号与登录](/troubleshooting/account/)，订阅类见[订阅与余额](/troubleshooting/billing/)，或通过官方群组联系我们。
