## 面板账号和 Emby 账号是两套

这是新订户最容易混淆的一点，先分清楚：

| | 面板账号 | Emby 账号 |
| --- | --- | --- |
| 用来做什么 | 管理订阅、充值、求片 | 在客户端里看片 |
| 在哪登录 | [面板网站](https://www.lumen.ax) | Emby 客户端 / 网页播放器 |
| 登录凭据 | 邮箱 + 面板密码 | Emby 用户名 + Emby 密码 + 线路地址 |
| 在哪改密码 | 面板 → 账号设置 | 面板 → 个人概览 |

客户端里填的永远是右边这套。**Emby 账号和密码在面板的「个人概览」页面查看和复制**，不是你注册面板时设置的那个密码。

## 客户端提示无法连接服务器

按顺序检查：

1. **服务器地址是否完整**：需要带 `https://` 前缀，逐字核对，注意结尾不要多出空格（复制粘贴时最容易带上）
2. **换一条线路**：到面板个人概览复制另一条线路地址再试，当前线路可能正在维护
3. **确认订阅状态**：订阅到期后 Emby 账号会被暂时停用，续费后立即恢复
4. **检查网络环境**：切换 Wi-Fi / 蜂窝数据再试，排除本地网络问题

## 登录成功但看不到内容

- 刚完成订阅：稍等片刻，账号开通有短暂延迟，退出客户端重新登录即可
- 订阅刚到期后续费：重新登录一次客户端刷新状态

## 收不到验证码邮件

1. 翻一下邮箱的**垃圾邮件箱**，验证码邮件常被误判
2. 等待一分钟后点击重新发送
3. 仍收不到：换个邮箱注册，或通过官方 Telegram / Discord 群组联系我们

## 忘记密码

- **忘记面板密码**：在登录页点击「忘记密码」，通过注册邮箱收取重置链接
- **忘记 Emby 密码**：登录面板，在**个人概览**的 Emby 登录信息里直接查看或重置

## 两步验证无法通过

验证器 App 丢失或换手机后无法生成动态码时，请通过官方群组联系管理员，核实身份后为你解绑。

## 账号安全建议

- 在面板**账号设置**中开启两步验证
- 不要与他人共享账号：账号仅限本人使用，异常多设备并发会触发风控，详见[服务条款](/legal/terms/)
- 发现账号异常：立即修改密码，并在账号设置中「在所有设备上退出登录」
