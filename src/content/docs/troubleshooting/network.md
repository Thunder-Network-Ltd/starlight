线路与流量的基础概念，请参阅[套餐、线路与流量](/start/plans/)。本页仅介绍出现问题时的处理方法。

## 某条线路无法连接

1. 确认地址是从控制台「播放线路」中**复制**的。请勿手动输入，也请勿使用他人提供的地址
2. 更换另一条线路：如能连接，说明问题出在原线路，该线路可能正在维护，请查看控制台顶部的系统通知
3. 所有线路均无法连接：请先检查本地网络，再确认订阅未到期

## 可以登录并浏览海报，但无法播放

- **使用了套餐范围以外的线路**：各套餐可用的线路不同，他人提供的线路地址或升级前记录的地址可能已不在您的套餐范围内。请返回控制台「播放线路」重新复制
- **套餐刚刚变更**：升级或到期后，可用线路会随之变化，客户端中的旧地址需要更新
- **本期流量已用完**：流量用完后播放会暂停，详见[流量用完后无法播放](#流量用完后无法播放)
- **网页播放器**：网页仅支持 HTTPS 直连线路，部分线路仅限在客户端中使用

## 晚高峰卡顿，白天正常

晚高峰是国际出口最拥堵的时段，此类问题源于网络层面：

- 更换线路进行对比，找到在该时段表现最稳定的线路
- 同一部影片先观看较低规格的版本
- 如每天晚高峰均出现卡顿，可在[官网套餐页](https://www.lumen.ax/#plans)比较各套餐包含的线路，选择更适合您网络环境的套餐

## 流量消耗超出预期

1. **查看线路倍率**：在控制台「播放线路」中，带有橙色「流量 ×N」标签的线路会按倍数计入流量
2. **4K 原盘流量消耗较大**：观看一小时 4K Remux 可能消耗 25–45 GB，详见[流量参考](/start/plans/#流量参考)
3. **客户端在后台预加载**：部分客户端会预先缓冲后续内容或下一集，这部分数据同样计入流量，可在客户端设置中关闭不需要的预加载功能
4. **下载到本地**：在客户端中下载影片与在线播放消耗同样多的流量
4. **账号被他人使用**：前往「账号设置 → 播放设备」检查是否存在陌生设备。如有，请移除该设备并修改密码

## 流量用完后无法播放

本期已用流量达到套餐额度后，播放将暂停，客户端与网页播放均无法开始新的播放，个人概览会显示「本期流量已用完」。账号不会被退出登录，您仍可登录、浏览片库和查看用量。

恢复方法：

- **升级套餐**：升级后从当时起开始新的计费周期，流量重新计算
- **等待下一计费周期**：进入新周期后自动恢复；个人概览的提示中会注明新周期的开始日期

提前续费同一套餐只顺延到期日，不会重置当前周期的流量。

## 流量计数何时清零

流量按计费周期计算：自订阅生效时起，每一个月为一个周期，进入新周期后已用流量从 0 重新计算。升级套餐，或订阅到期后重新续订（包括自动续订），均从当时起开始新的周期。

您可以在控制台个人概览的「流量信息」卡片中查看当前用量；用量达到提醒阈值（默认 90%）时，您将收到提醒邮件。

## 仍无法解决

请前往 [Telegram 交流群](https://t.me/Lumen_MediaCN)反馈，并提供**您的运营商和所在地区、所用线路以及出现问题的时间段**，以便我们排查线路问题。
