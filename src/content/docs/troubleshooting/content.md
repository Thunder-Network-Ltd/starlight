想看的资源片库里没有、或者现有资源有问题，都通过面板的**片库反馈**页面提交。这一页说明怎么提交效率最高。

## 如何求片

在片库反馈页面选择**影片请求**：

1. 到 [TMDB](https://www.themoviedb.org/) 或[豆瓣](https://movie.douban.com/)搜索你想看的影片，打开它的**详情页**，复制浏览器地址栏的链接
2. 把链接粘贴到「影片链接」栏
3. 补充说明可选：例如指定某个版本、某季某集

:::tip
一定要贴详情页链接而不是搜索结果页——同名影片很多，链接能让我们准确定位到你要的那一部。
:::

## 求片之后会发生什么

提交后可在**我的反馈**中跟踪状态：

| 状态 | 含义 |
| --- | --- |
| 等待处理 | 已收到，排队中 |
| 寻找资源 | 正在寻找合适的资源版本 |
| 资源下载中 | 已找到资源，入库中 |
| 处理完成 | 已上架，可以观看了 |
| 处理异常 | 暂时无法处理，见管理员回复 |

刚上映的影片需要等高清资源发布后才能入库，这类请求处理周期会长一些，请耐心等待。

## 如何反馈资源问题

缺集、坏档、音画错误、字幕缺失这类问题，选择**错误反馈**：

1. 填写**出错媒体的标题**
2. 描述问题：**剧集请具体到第几季第几集**，例如「第 2 季第 5 集没有中文字幕」
3. 可以附上该影片的 Emby 页面链接，方便快速定位

:::note
先区分是资源问题还是播放问题：换一个客户端播放同一影片，如果都异常才是资源问题；
只在某个客户端异常，多半是播放设置问题，先看[播放问题排查](/troubleshooting/playback/)。
:::

## 追更的剧多久更新一集？

热门剧集一般在资源发布后尽快入库。如果某部剧长时间没有更新，欢迎通过片库反馈提醒我们。
